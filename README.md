# JavaScript Concepts with DSA 🚀

This repository is a **comprehensive guide to JavaScript**, covering **basic, intermediate, and advanced concepts**, along with **Data Structures and Algorithms (DSA)** implementations using JavaScript.

It is designed for:

* 📚 Learning JavaScript step by step
* 🧠 Strengthening problem-solving skills with DSA
* 💼 Interview preparation
* 🔁 Quick revision and reference

---

## 🟢 JavaScript Basics

* Variables: `let`, `var`, `const`
* Data Types & Type Coercion
* Operators & Control Statements
* Loops: `for`, `forEach`, `for...of`, `for...in`
* Functions & Scope
* Math Methods
* String & Array Basics
* Objects & Properties
* DOM Introduction

---

## 🟡 Intermediate JavaScript

* Function Types (Named, Anonymous, Arrow, IIFE)
* Callback Functions & Callback Hell
* Higher-Order Functions
* Array Methods (`map`, `filter`, `reduce`)
* Closures & Hoisting
* Execution Context
* Event Handling
  * Event Bubbling & Capturing
  * Event Delegation
* Promises & Async/Await
* LocalStorage & SessionStorage
* Shallow Copy vs Deep Copy
* Template Literals & Destructuring
* Call, Apply, Bind

---

## 🔴 Advanced JavaScript

* Event Loop (Microtasks & Macrotasks)
* Debouncing & Throttling
* Lazy Loading & Memoization
* Currying
* Prototype vs Class
* Async vs Defer
* Synchronous vs Asynchronous JavaScript
* Performance Optimization Concepts
* Memory Management Basics

---

## 🎯 Goal of This Repository

To build a **strong JavaScript foundation**, master **core concepts**, and apply them effectively in **DSA and real-world applications**.
